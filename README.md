# Web Store Project

A simple e-commerce website built using HTML, CSS, and JavaScript.

---

## Features
- Browse products
- View product details
- Add to cart and favorites
- Login and signup forms
- Dynamic product details using URL parameters

---

## Pages

- **home.html** – Main page showing products
- **about.html** – Information about the website
- **product.html** – Product listing page
- **details.html** – Product details page
- **login.html** – Login and signup interface
- **contact.html** – Contact page

---

## Technologies
- HTML
- CSS
- JavaScript
